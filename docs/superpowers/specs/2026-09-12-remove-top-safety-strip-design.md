# 移除工作台顶部安全状态条设计

## 目标

从 Svarog 工作台完全移除顶部“● 核心工作流只读 · 未自动处置”状态条，以及新建调查标题下方的流程说明，使页面更简洁、专业。

## 修改范围

- 删除 `src/svarog/webui/assets/index.html` 中的整段状态条元素，而不是仅通过 CSS 隐藏。
- 删除“告警 → Agent 分析 → 日志查询 → IOC → ATT&CK → 建议 → 人工确认。”流程说明，不增加替代文字。
- 删除只服务于该元素、且不再被其他组件使用的 CSS 规则。
- 调整静态资源测试，明确断言该文案和对应样式不存在。
- 安全边界说明继续保留在 README 和《UI使用说明》中，不改变任何后端安全策略或业务流程。

## 验收标准

1. 页面顶部不再出现圆点或“核心工作流只读 · 未自动处置”文案。
2. “新建告警调查”下方不再显示流程说明。
3. 删除后不保留空白占位。
4. 导航、标题、功能表单和响应式布局不受影响。
5. Web UI 静态测试与完整回归测试通过。
