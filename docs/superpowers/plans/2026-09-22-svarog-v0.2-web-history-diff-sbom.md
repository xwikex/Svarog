# Svarog v0.2 Web History, Diff, and SBOM Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add persistent, deduplicated audit history, semantic comparison, bounded retention, and reproducible CycloneDX 1.7 SBOM downloads to Svarog's local Web UI without changing the existing CLI contract.

**Architecture:** Add isolated `audit_history`, `audit_diff`, and `sbom` domain packages. The Web UI calls these packages through small API adapters; SQLite stores normalized query rows plus a compressed authoritative JSON result. Existing audit services remain responsible for inventory and vulnerability matching.

**Tech Stack:** Python 3.11+, standard-library SQLite/zlib/hashlib/uuid/pathlib, `packaging`, `jsonschema` 4.x, pytest 8, native HTML/CSS/JavaScript.

```python
@dataclass(frozen=True, slots=True)
class RuntimeLayout:
    workspace: Path
    root: Path
    config_dir: Path
    database_dir: Path
    backup_dir: Path
    reports_dir: Path
    cache_dir: Path
    logs_dir: Path
    temp_dir: Path
    project_file: Path
    settings_file: Path
    history_db: Path
    case_db: Path

    @classmethod
    def build(cls, workspace: str | Path) -> "RuntimeLayout":
        resolved = Path(workspace).resolve(strict=True)
        root = resolved / ".svarog"
        config = root / "config"
        database = root / "database"
        reports = root / "reports"
        return cls(
            workspace=resolved,
            root=root,
            config_dir=config,
            database_dir=database,
            backup_dir=database / "backups",
            reports_dir=reports,
            cache_dir=root / "cache",
            logs_dir=root / "logs",
            temp_dir=root / "temp",
            project_file=config / "project.json",
            settings_file=config / "settings.json",
            history_db=database / "audit-history.sqlite3",
            case_db=database / "cases.sqlite3",
        )

    def ensure_directories(self) -> None:
        for directory in (
            self.config_dir, self.database_dir, self.backup_dir,
            self.reports_dir / "audits", self.reports_dir / "differences",
            self.reports_dir / "sbom", self.reports_dir / "cases",
            self.cache_dir, self.logs_dir, self.temp_dir,
        ):
            directory.mkdir(mode=0o700, parents=True, exist_ok=True)


@dataclass(frozen=True, slots=True)
class ProjectIdentity:
    schema_version: int
    project_id: str
    display_name: str
    created_at: str


@dataclass(frozen=True, slots=True)
class RuntimeSettings:
    schema_version: int = 1
    audit_retention_days: int = 180
```

def immediate_transaction(connection: sqlite3.Connection) -> Iterator[sqlite3.Connection]:
