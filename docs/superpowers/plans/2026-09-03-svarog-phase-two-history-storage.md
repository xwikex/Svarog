# Svarog Phase Two History Storage Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the safe, versioned SQLite history-storage foundation that records projects, runs, deduplicated audit snapshots, normalized packages, and normalized findings without yet changing the public `audit-project` CLI.

**Architecture:** Add a focused `svarog.history` package. `HistoryDatabase` owns safe path preparation, SQLite configuration, schema migration, transactions, compression validation, run lifecycle, and race-safe snapshot persistence. Hash calculation, CLI wiring, semantic diffing, and SBOM generation remain separate follow-up plans and consume this storage API.

**Tech Stack:** Python 3.11+ standard library (`sqlite3`, `zlib`, `hashlib`, `json`, `uuid`, `pathlib`), immutable dataclasses, pytest 8.

---

## Scope boundary

This plan implements section 14.1 of
`docs/superpowers/specs/2026-09-03-svarog-phase-two-history-diff-sbom-design.md`.

It deliberately does not:

- add `--history-db` or `--project-id` to the CLI;
- calculate semantic hashes;
- choose a historical baseline;
- create `run_diffs`;
- generate CycloneDX;
- add an LRU cache.

Those features depend on this storage layer and receive separate implementation plans.

- [ ] **Step 4: Implement safe database creation and migration**

Create `src/svarog/history/database.py` with a `HistoryDatabase` class that:

1. fixes the parent directory with `resolve(strict=True)`;
2. rejects empty, `.` and `..` filenames;
3. rejects existing symlinks, non-regular files, and files with `st_nlink > 1`;
4. creates a missing file with
   `os.open(path, os.O_RDWR | os.O_CREAT | os.O_EXCL | getattr(os, "O_BINARY", 0), 0o600)`;
5. connects with `isolation_level=None` and `timeout=5.0`;
6. sets `row_factory=sqlite3.Row`, foreign keys, and busy timeout;
7. runs `PRAGMA quick_check(1)`, reads application ID, user version, and user-table names
   before enabling any mutating journal setting;
8. rejects an unrelated non-empty SQLite file whose application ID is not `APPLICATION_ID`
   without switching it to WAL;
9. rejects `user_version > CURRENT_SCHEMA_VERSION` before changing journal mode;
10. after recognizing a compatible new or Svarog file, enables WAL and FULL synchronous mode;
11. applies migrations one version at a time with `connection.executescript`, where each
    trusted migration script contains its own `BEGIN IMMEDIATE` and `COMMIT`;
12. writes `application_id`, `user_version`, and `schema_meta` in the same migration transaction;
13. exposes `connection`, `schema_version`, `close()`, `__enter__`, and `__exit__`.

Do not wrap `executescript` in the helper below because `executescript` has its own transaction
boundary behavior. Migration scripts own their explicit transaction. Use this helper for all
non-migration write operations so every rollback path is explicit:

```python
from contextlib import contextmanager
from collections.abc import Iterator
import sqlite3


@contextmanager
def immediate_transaction(
    connection: sqlite3.Connection,
) -> Iterator[sqlite3.Connection]:
    connection.execute("BEGIN IMMEDIATE")
    try:
        yield connection
    except BaseException:
        connection.rollback()
        raise
    else:
        connection.commit()
```

Create `src/svarog/history/codec.py` with this implementation:

```python
from __future__ import annotations

from collections.abc import Mapping
import hashlib
import hmac
import json
import re
import zlib

from .errors import HistoryDatabaseError


MAX_RESULT_JSON_BYTES = 16 * 1024 * 1024
MAX_COMPRESSED_RESULT_BYTES = 16 * 1024 * 1024
_SHA256 = re.compile(r"^[0-9a-f]{64}$")


def _reject_constant(_value: str) -> object:
    raise ValueError("non_finite_json")


def encode_result(
    result: Mapping[str, object],
) -> tuple[bytes, int, str]:
    try:
        payload = json.dumps(
            result,
            ensure_ascii=False,
            sort_keys=True,
            separators=(",", ":"),
            allow_nan=False,
        ).encode("utf-8")
    except (TypeError, ValueError, UnicodeError, RecursionError):
        raise HistoryDatabaseError("invalid_snapshot_result") from None
    if len(payload) > MAX_RESULT_JSON_BYTES:
        raise HistoryDatabaseError("snapshot_too_large")
    compressed = zlib.compress(payload, level=9)
    if len(compressed) > MAX_COMPRESSED_RESULT_BYTES:
        raise HistoryDatabaseError("snapshot_too_large")
    return compressed, len(payload), hashlib.sha256(payload).hexdigest()


def decode_result(
    compressed: bytes,
    expected_size: int,
    expected_sha256: str,
) -> dict[str, object]:
    if (
        not isinstance(compressed, bytes)
        or isinstance(expected_size, bool)
        or not isinstance(expected_size, int)
        or expected_size < 0
        or not isinstance(expected_sha256, str)
        or not _SHA256.fullmatch(expected_sha256)
    ):
        raise HistoryDatabaseError("snapshot_corrupt")
    if (
        expected_size > MAX_RESULT_JSON_BYTES
        or len(compressed) > MAX_COMPRESSED_RESULT_BYTES
    ):
        raise HistoryDatabaseError("snapshot_too_large")

    decompressor = zlib.decompressobj()
    output = bytearray()
    try:
        for offset in range(0, len(compressed), 64 * 1024):
            chunk = compressed[offset : offset + 64 * 1024]
            remaining = MAX_RESULT_JSON_BYTES + 1 - len(output)
            output.extend(decompressor.decompress(chunk, remaining))
            if len(output) > MAX_RESULT_JSON_BYTES or decompressor.unconsumed_tail:
                raise HistoryDatabaseError("snapshot_too_large")
        output.extend(
            decompressor.flush(MAX_RESULT_JSON_BYTES + 1 - len(output))
        )
    except HistoryDatabaseError:
        raise
    except (ValueError, zlib.error):
        raise HistoryDatabaseError("snapshot_corrupt") from None

    if len(output) > MAX_RESULT_JSON_BYTES:
        raise HistoryDatabaseError("snapshot_too_large")
    payload = bytes(output)
    if (
        not decompressor.eof
        or decompressor.unused_data
        or len(payload) != expected_size
        or not hmac.compare_digest(
            hashlib.sha256(payload).hexdigest(), expected_sha256
        )
    ):
        raise HistoryDatabaseError("snapshot_corrupt")
    try:
        value = json.loads(
            payload.decode("utf-8", errors="strict"),
            parse_constant=_reject_constant,
        )
    except (UnicodeError, json.JSONDecodeError, ValueError, RecursionError):
        raise HistoryDatabaseError("snapshot_corrupt") from None
    if not isinstance(value, dict) or not all(
        isinstance(key, str) for key in value
    ):
        raise HistoryDatabaseError("snapshot_corrupt")
    return value
```

`encode_result` must use:

```python
json.dumps(
    result,
    ensure_ascii=False,
    sort_keys=True,
    separators=(",", ":"),
    allow_nan=False,
).encode("utf-8")
```

Reject non-object roots, oversized uncompressed data, and oversized compressed data.
Return `(zlib.compress(payload, level=9), len(payload), sha256(payload).hexdigest())`.

`decode_result` must reject invalid field types and lengths before decompression. Use
`zlib.decompressobj()` in 64 KiB input chunks and cap cumulative output at
`MAX_RESULT_JSON_BYTES + 1`; do not call unbounded `zlib.decompress`. Require `eof`, no
unused/trailing data, exact uncompressed length, exact SHA-256, strict UTF-8, finite JSON
numbers, and an object root. Map every validation failure to `snapshot_corrupt`, except
declared or actual size overflow, which maps to `snapshot_too_large`.

The module must not contain `functools.lru_cache` or a process-global result dictionary.

Use this CTE so the run ID and timestamp always come from the same earliest row:

```sql
WITH ranked AS (
    SELECT
        r.project_id,
        f.advisory_key,
        f.normalized_name,
        f.package_version,
        f.evidence_layer,
        r.run_id,
        r.finished_at,
        ROW_NUMBER() OVER (
            PARTITION BY
                f.normalized_name,
                f.package_version,
                f.evidence_layer
            ORDER BY r.finished_at ASC, r.run_id ASC
        ) AS ordinal
    FROM audit_runs AS r
    JOIN snapshot_findings AS f ON f.snapshot_id = r.snapshot_id
    WHERE r.project_id = ?
      AND f.advisory_key = ?
      AND r.run_status IN ('completed_computed', 'completed_reused')
      AND r.finished_at IS NOT NULL
)
SELECT
    project_id,
    advisory_key,
    normalized_name,
    package_version,
    evidence_layer,
    run_id,
    finished_at
FROM ranked
WHERE ordinal = 1
ORDER BY normalized_name, package_version, evidence_layer
LIMIT 10000
```

Python 3.11's supported SQLite versions provide window functions.

## Completion criteria

This plan is complete only when:

- a new history database can be created, closed, reopened, and version-validated;
- unrelated, corrupt, unsafe, and too-new databases fail with fixed errors;
- started, failed, and explicitly interrupted runs are durable;
- one computed snapshot and multiple reused runs can coexist;
- packages and findings are queryable without decoding JSON;
- summary metrics are queryable without decoding JSON;
- `get_snapshot_result` validates compressed length, digest, JSON shape, and size bounds;
- two concurrent writers produce one snapshot and two successful runs;
- first-seen queries are project-scoped, deterministic, bounded, and indexed;
- no LRU cache, CLI integration, hash calculation, diff engine, or SBOM exporter has leaked
  into this checkpoint;
- the complete existing Svarog test suite remains green.
