# Svarog 本地告警 SOP 增量实现

保留 analyze、audit-python、audit-project 和范围锁定的 doctor；新增独立 sop 包和案件库，不依赖未合并的历史审计代码。

## 范围

1. 接收显式告警 JSON（时间必须含时区，来源 IP / 主机至少一个）。
2. 本地 Agent 生成受限查询计划；可选模型只辅助解读，不获得执行工具。
3. 显式读取 JSONL 或 Nginx combined 日志；按时间窗口和告警选择器关联，不自动发现主机文件。combined 格式不含主机，必须显式提供日志主机。
4. 从关联日志提取待验证 IOC，并保留行号和证据引用。
5. 基于既有 Web 检测规则给出少量 ATT&CK 候选；不将攻击尝试或 HTTP 200 解释为入侵成功。
6. 生成有证据引用、影响说明的处置建议；可选模型故障时明确降级。
7. 独立 SQLite 保存案件与一次人工复核记录。批准仅记录决定，绝不执行封禁/命令。

JSON 为事实源，HTML 为无脚本、无外部资源的渲染壳。报告包含七阶段、查询覆盖、证据、IOC、映射、建议及复核状态。

## 实施顺序与验证

- 先写解析、查询、证据链、复核状态和 CLI 冒烟测试，确认失败。
- 实现有大小限制的输入、流程服务、独立数据库、报告与命令入口。
- 模型仅接受显式配置的服务；不上传原始日志，输入和输出均不可信。
- 验证无结果/坏行/截断、HTML 注入、输出路径冲突、未知数据库、重复复核和模型异常。
- 跑原有测试、新增测试，生成本地演示报告与 Windows 操作说明。

## 明确限制

不是自动响应平台；不提供 SIEM/EDR 连接、后台监听、完整 ATT&CK、自动处置或身份认证。人工姓名为个人本地记录，不是企业级签名。日志/报告可能含敏感内容，须自行保护。案件库与漏洞库分离。
